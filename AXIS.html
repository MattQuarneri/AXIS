Architecture for humans & agents

Give every piece
of code a home.

AXIS is a placement grammar for code: keep business rules pure, put IO at the edge, and give every piece of mutable state one owner.

Agentically eXtensible Instruction Structures. Seven concerns, each with a definition and a live counterpart. Use the roles to reason about your code, in your repository’s own names.

01 / Install once

Bring AXIS into your agent.

Download the ZIP and choose your tool below. The package contains the core instructions, references, examples, and a repository mapper. Keep the entire axis/ folder together.

CODEX · CLI & IDE

Install the skill folder

Extract the ZIP. Put its axis/ folder in one of these locations:

For yourself, across repositories

~/.agents/skills/axis/SKILL.md

For a project, committed with the repository

.agents/skills/axis/SKILL.md

Use /skills or type $axis to select it. If it does not appear, restart Codex.

Publishing AXIS on your own website

Upload this page with presentations/ and skill/ beside it. Preserve the skill folder structure: the agent index links to its references, script, examples, and license. Its optional links also point to the parent AXIS source documents.

AXIS/
  AXIS.html
  presentations/…
  skill/
    axis.skill
    llms.txt
    llms-full.txt
    axis/
      SKILL.md
      references/…
      scripts/axis.py
      assets/…
      LICENSE.txt
      NOTICE.txt

The ZIP button downloads axis.skill with the filename axis.zip; both contain the same ZIP archive. The URL prompt assumes the files are published at https://mentic.com/AXIS/skill/. If you host elsewhere, update that prompt.

Hosting makes the files available. Visitors still install the skill in their agent or explicitly ask the agent to read the published instructions.

Building and updating the package

In the source repository, run these commands from architectures/AXIS/skill/:

python3 build.py
python3 build.py --check

The builder regenerates the assembled references, agent pages, and axis.skill. Publish them together. People using downloaded copies need to install the updated package.

Distributing through an OpenAI plugin

For installation through the OpenAI plugin directory, package AXIS as a plugin. This is a separate distribution step from hosting these files. OpenAI recommends plugins for distributing reusable skills beyond a single repository.
